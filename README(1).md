## Repository structure

```text
Portfolio-Suhani-Balchandani/
├── index.html    # Production Framer export
└── README.md     # Project documentation
```

The repository contains a production export generated by Framer. Fonts, images,
and runtime modules are loaded from Framer-hosted resources.

## Run locally

Clone the repository:

```bash
git clone https://github.com/suhaniibalchandanii/Portfolio-Suhani-Balchandani.git
cd Portfolio-Suhani-Balchandani
```

Start a local HTTP server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

An internet connection is required because the exported page loads its fonts,
images, and JavaScript modules from Framer’s CDN.

> [!NOTE]
> This repository currently contains only the landing-page export. Internal
> links such as `/projects` require their corresponding exported route files or
> the live Framer deployment.

## Deployment

The canonical version is published through Framer:

**[visual-development-421176.framer.app](https://visual-development-421176.framer.app/)**

The landing page can also be hosted as a static site:

1. Open the repository’s **Settings**.
2. Select **Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for the deployment to complete.

For complete project routes, export and commit all related pages before using a
static host.
